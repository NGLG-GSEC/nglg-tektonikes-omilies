# Fiore Rubinetterie — ελληνικός ιστότοπος

Στατικός ιστότοπος μόνο στα ελληνικά (HTML/CSS/JS, χωρίς build). Άνοιγμα: `fiore/index.html`.

| Σελίδα | Περιεχόμενο |
|---|---|
| `index.html` | Αρχική: hero, επιλεγμένες σειρές, Collezione Primavera, Easy Cover, ιστορία |
| `seires.html` | Όλες οι σειρές με φίλτρα κατηγορίας, αναζήτηση και παράθυρο με φωτογραφίες και φινιρίσματα |
| `finirismata.html` | Φινιρίσματα κατά κατηγορία (Βασικά, Πολύτιμα μέταλλα, Primavera Matt, Primavera Met) και πίνακας διαθεσιμότητας |
| `katalogos.html` | Κατάλογοι (δημόσιοι και B2B) |
| `b2b.html` | Πύλη B2B: είσοδος συνεργατών, οφέλη, αίτηση πρόσβασης |
| `etaireia.html`, `epikoinonia.html` | Εταιρεία, επικοινωνία |

## Ρυθμίσεις

Στο `js/data.js`, στο `FIORE_CONFIG`:

- `b2bUrl`: ο σύνδεσμος της πύλης B2B (π.χ. το GitHub Pages του B2B αποθετηρίου). Μέχρι να οριστεί, το κουμπί «Είσοδος» οδηγεί στη φόρμα αίτησης.
- `email`: η διεύθυνση που δέχεται τις φόρμες (mailto).

Οι σειρές (`FIORE_SERIES`) και τα φινιρίσματα (`FIORE_FINISHES`) ορίζονται στο ίδιο αρχείο. Οι φωτογραφίες βρίσκονται στο `img/` σε μορφή WebP. Προέρχονται από το φωτογραφικό αρχείο Fiore στο Google Drive.

## Έκδοση ενός αρχείου

`dist/fiore-gr.html` περιέχει ολόκληρο τον ιστότοπο (σελίδες, CSS, JS, εικόνες) σε ένα αυτόνομο HTML που ανοίγει με διπλό κλικ ή ανεβαίνει ως `index.html` σε οποιονδήποτε host. Μετά από αλλαγές, ξαναχτίζεται με:

    python3 tools/build-single.py
